# NexaChat – AI-Powered Chatbot

NexaChat is a full-stack AI chatbot application inspired by ChatGPT. It allows users to interact with an AI assistant, receive AI-generated responses, and manage conversation history through a clean web interface.

## Features

- AI-powered conversations using the OpenAI API
- Interactive chat interface
- Create new conversations
- View and switch between saved conversations
- Delete conversation history
- Render formatted AI responses using Markdown
- Syntax highlighting for code snippets
- Persistent conversation storage using MongoDB

## Technologies Used

**Frontend**
- React.js
- Vite
- JavaScript
- HTML5 and CSS3
- React Markdown

**Backend**
- Node.js
- Express.js
- REST APIs
- OpenAI API

**Database**
- MongoDB
- Mongoose
